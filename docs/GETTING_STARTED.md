# 启动指南

当前启动、测试和功能边界以 [根 README](../README.md) 为准。服务必须从仓库根目录通过 `python run_backend.py` 启动，或设置 PYTHONPATH 同时包含仓库根目录与 business_logic。

页面由 React/Vite 提供，API 经 Vite `/api` 代理访问 8000 端口。不能直接双击 index.html 运行。没有默认管理员密码；先注册账号。

首个演示：注册 A → 登录 → 合成回放 → 波形/模型未接入说明 → 历史回看。家庭流程：注册 B → A 对 B 授权 → B 查看共享记录 → A 撤回 → B 重新查询应被拒绝。

## 环境与验证边界

Python 3.10+，Node.js 20.19+ 或 22.12+；完整安装和验证命令见根 README。已有虚拟环境可能因原解释器路径失效而不能启动，应重建后再运行后端检查。2026-10-21 前端构建通过，后端本轮未能运行 pytest；历史通过记录不能当作当前全部测试已通过。详见[验证与审查](VALIDATION.md)。
