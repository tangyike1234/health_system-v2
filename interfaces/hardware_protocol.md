# 硬件通信协议

## 版本: 1.0 | 更新: 2026-10-19

## 概述

ECG 采集硬件与后台服务的通信协议。

## 参数

| 参数 | 值 |
|------|-----|
| 采样率 | 500 Hz |
| 分辨率 | 12 bit |
| 数据格式 | Binary (小端序) |

## 帧格式

```
SOF | LEN | CMD | PAYLOAD | CRC
```

## 命令码

| CMD | 名称 | 方向 |
|-----|------|------|
| 0x01 | DATA_FRAME | H→B |
| 0x02 | HEARTBEAT | H→B |
| 0x10 | START | B→H |
| 0x11 | STOP | B→H |
