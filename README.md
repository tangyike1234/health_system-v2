# ECG 智能分析系统

**日期**: 2026-10-19

## 项目概述

端到端 ECG 心电图智能分析系统。

## 🚀 快速启动

👉 详细运行指南: [docs/GETTING_STARTED.md](docs/GETTING_STARTED.md)

### 命令汇总

```bash
# 后端
cd business_logic
pip install -r requirements.txt
uvicorn app.main:app --reload --port 8000

# 前端 (新窗口)
cd frontend
npm install
npm run dev
```

## 技术栈

- **前端**: React + TypeScript + Vite
- **后端**: FastAPI + Python
- **数据库**: SQLite / PostgreSQL
- **AI**: TensorFlow / ONNX
- **硬件**: STM32
